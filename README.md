# Weather Outfit App (v7)

실시간 현장 제보 취소 기능이 추가된 최신 버전입니다.

## 🌟 이번 버전의 주요 추가 및 변경 사항
1. **잘못 등록된 제보 취소 기능:**
   - [현장 날씨 제보하기] 탭 하단에 '내가 등록한 최근 제보' 목록이 나타납니다.
   - 잘못 작성하거나 취소하고 싶을 때 **[제보 취소]** 버튼을 누르면 해당 제보가 집계 대상에서 즉시 삭제됩니다.
   - 제보가 취소되면 목적지 선택 시 계산되는 오늘자 제보 퍼센트(%) 요약 통계에도 즉각 반영됩니다.
2. **기존 기능 유지:**
   - 전국 17개 시/도 전체 지원
   - 선택된 목적지에 제보가 있을 때만 퍼센트(%) 통계 노출
   - `단어:설명` 형식 및 특수문자 제거 AI 옷차림 추천

## 📁 파일 구조
- `package.json`: Vercel ESM 설정 (`"type": "module"`)
- `index.html`: 프론트엔드 (내 제보 목록 & 삭제 취소 버튼 + 퍼센트 통계 UI)
- `api/generate.js`: 백엔드 서버리스 함수 (Open-Meteo & Gemini API 연동)
- `README.md`: 프로젝트 안내 문서

## 🚀 배포 방법
1. 압축을 해제한 프로젝트 파일 전체를 GitHub 저장소에 올립니다.
2. Vercel에서 저장소를 불러옵니다.
3. `GEMINI_API_KEY` 환경변수를 설정하고 배포를 진행합니다.
